Pyrophobia

Raise a torch. Make wildlife think twice.

Pyrophobia is a fire-driven wildlife deterrence mod for Vintage Story.

Hold right-click with a lit main-hand torch to brandish it. Nearby hostiles that are targeting you may break off and flee while it is raised.

Ground fires, richer animal reactions, and configuration are planned for later releases (WIP).

What Pyrophibia changes

  • Brandish stance: raise a lit torch in first and third person (open air / creature aim). Block-targeted use stays vanilla: place, relight, shift-ignite.
  • Scare hostiles: animals actively targeting you can flee while you brandish (chance-based, server-side).

Compatibility and installation

  • Built for Vintage Story 1.22.3.
  • Required on both the client and server.
  • Standalone, with no required dependencies.

 

Download the matching zip from the Files tab or use 1-click install. For a manual installation, place the zip in the Vintage Story Mods directory without unpacking it, then restart the game or server.
