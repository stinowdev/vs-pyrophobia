Pyrophobia

Fire changes how wildlife sees you

Pyrophobia is a fire-driven wildlife deterrence mod for Vintage Story. The planned core mechanic lets a player raise a main-hand torch to scare off or discourage hostile animals.

Fire sources in the world, including ground torches and firepits, will also influence nearby animal behavior. Some animals may retreat from fire, while hungry hunters may investigate an isolated fire instead. These reactions are intended to be configurable.

Features

  • Raised torch: deter hostile animals that are attacking or pursuing the player.
  • Environmental fire: let torches, firepits, and other fire sources influence wildlife.
  • Configurable reactions: tune ranges, probabilities, and animal responses.

Compatibility and installation

  • Targeted at Vintage Story 1.22.3.
  • Required on both the client and server.
  • Standalone, with no required dependencies.

Download the matching zip from the Files tab or use 1-click install. For a manual installation, place the zip in the Vintage Story Mods directory without unpacking it, then restart the game or server.

Project status

This is an early development baseline. The project currently contains the mod scaffold and design contract; gameplay behavior is not implemented yet.
